PORTFOLIO NJIKE — VERSION REFONDUE

Fichiers :
- index.html : page complète, contenu et coordonnées conservés.
- style.css : nouvelle identité visuelle bleu électrique / noir bleuté / vert citron.
- script.js : menu mobile, animations progressives, compteurs, progression de lecture, retour en haut et lightbox accessible.
- assets/ : images et favicons extraits du HTML original pour éviter les énormes chaînes base64 dans index.html.

Installation : téléversez index.html, style.css, script.js et le dossier assets/ ensemble dans le même répertoire de votre hébergement. Gardez une copie de l’ancien site avant remplacement.

Notes : vérifiez les chiffres de la section statistiques avant publication. Les polices sont chargées depuis Google Fonts ; une connexion Internet est nécessaire pour les charger. Les liens de contact originaux ont été conservés.
